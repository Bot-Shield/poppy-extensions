# Contributing

Issues and pull requests are welcome: gaps in the specs, cases they don't cover, and implementation
reports from Companies and personal agents.

- A change to a spec says which section it changes and why, with an example.
- A change to `@botshield/poppy` comes with a test. Run `npm test` and `npm run typecheck` in
  `packages/poppy`.
- Contributions are accepted under the [Apache 2.0](LICENSE) license.
